## 2. 详情弹窗渲染增强 (`showItemDetail`)

### 2.1 照片字段处理

**编辑态：**
- 渲染 80×80 虚线边框上传区
- 内含：预览图 (`.photo-preview`) + 加号图标 (`.photo-icon-wrap`) + 相机角标 (`.photo-camera-wrap`)
- 点击触发 `simulatePhotoUpload(this)` → 设置占位图 URL、隐藏加号、显示预览 & 相机角标
- 照片值存入 `type="hidden"` 的 input（带 `data-field` 索引，与字段数组对齐）

**查看态：**
- 有照片：显示缩略图
- 无照片：显示灰色占位图

### 2.2 职责清单字段处理

- **编辑态**：多行文本框 (`textarea`, 4 行)
- **查看态**：`\n` → `<br>` 渲染保留换行

### 2.3 其他调整

- `isNew` 条件扩展为 `key === 'empNew' || key === 'licenseNew' || key === 'adminNew'`
- `isEmployee` (OCR 触发条件) 保持 `key.startsWith('emp')`，管理员不触发健康证 OCR

## 3. 新增函数

### `simulatePhotoUpload(btn)`

```
参数: 按钮 DOM 元素
行为:
  1. 设置 .photo-preview 的 src 为占位图 URL
  2. 显示预览图、隐藏加号图标 wrap、显示相机角标 wrap
  3. 更新同层 .photo-input (hidden) 的 value
  4. 弹出 toast "照片上传成功"
```

## 4. 健康证 OCR 模拟 (`simulateEmpOCR`) 调整

## 6. 列表项 Avatar 结构

从业人员和食品安全管理员的列表头像统一使用以下结构（便于后续 js 动态加载照片）：

```html
<div class="w-10 h-10 rounded-full bg-[color]-100 ... overflow-hidden">
  <img src="" alt="" class="hidden w-full h-full object-cover [prefix]-avatar" data-[prefix]="[key]">
  <span class="[prefix]-avatar-fallback">[姓氏]</span>
</div>
```

- 从业人员: `emp-avatar` / `emp-avatar-fallback`
- 食品安全管理员: `admin-avatar` / `admin-avatar-fallback`
