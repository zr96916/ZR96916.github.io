## 一、概述

### 1.1 产品简介

「智慧食安」是一套面向食品安全监管的全流程数字化平台，分为**管理端（PC 端）**与**商户端（小程序）**两端：

- **管理端**：面向区/镇市场监管部门工作人员，用于辖区食品经营主体的统一监管、AI 报警处置、审批流转、公告下发、站内沟通与系统运维。按角色分权：区级管理员统筹全区，镇级管理员负责本镇并拥有唯一审批权。
- **商户端**：面向食品经营商户的移动端小程序，用于接收整改通知、管理证照与人员信息、上报进货查验、绑定微信接收告警通知等。

**两端核心模块速览：**

| 端 | 核心模块 |
|---|---|
| 管理端（PC） | 工作台、主体管理、视频监控、设备关联、风险预警、审批记录、站内信、公告管理、知识库、通知信息、系统管理 |
| 商户端（小程序） | 首页、工单、企业、我的（修改密码 / 绑定手机 / 通知接收） |

### 2.2 核心处理流程

本节梳理「智慧食安」的核心业务处理主流程与分支流程，覆盖「报警 → 处置 → 整改 → 审批 → 归档」全链路。

#### 主流程一：AI 报警处置

```text
AI 摄像头实时抓拍 → 识别违规（鼠患 / 未戴口罩 / 未戴帽子 / 垃圾桶未加盖 / 陌生人闯入 / 明火离人 / 抽烟）
        │
        ▼
风险预警 · 待审核（监管人工复核）
        │
        ├── 不采纳 ─────────────► 已撤销（流程结束）
        │
        └── 确认采纳 ───────────► 待整改（生成整改工单，下发商户）
                                        │
                                        ▼
                              商户小程序 · 工单（整改并提交材料）
                                        │
                                        ▼
                              审批记录 · 待审批（镇级管理员审核）
                                        │
                              ├── 审核通过 ──► 归档（已通过）· 报警状态 → 已确认
                              │
                              └── 驳回（填写原因）──► 已驳回（商户重新整改后再次提交，回到待审批）
                                        │
                              （累计驳回 3 次 → 系统自动关闭工单）
```

**步骤说明：**

1. **报警生成**：AI 摄像头对后厨实时抓拍，识别出违规行为后自动生成报警记录，进入「风险预警 → 待审核」。
2. **人工复核**：监管人员在风险预警详情中查看抓拍截图与置信度，作出判断。
   - **确认采纳**：报警状态变「待整改」，同时生成整改工单并下发至对应商户。
   - **不采纳**：报警状态变「已撤销」，流程结束。
3. **商户整改**：商户在小程序「工单」收到整改通知，按要求整改后提交材料（整改说明 + 照片）。
4. **镇级审核**：工单进入「审批记录 → 流转中（待审批）」，由镇级管理员审核：
   - **审核通过**：工单归档（已通过），对应报警状态变「已确认」。
   - **驳回**：须填写驳回原因，工单状态变「已驳回」；商户重新整改后再次提交，自动回到「待审批」。
5. **自动关闭**：同一工单累计驳回 3 次，系统自动关闭。

#### 主流程二：证照到期预警处置

```text
证照扫描规则（每日 02:00）→ 命中提醒节点（90 / 60 / 30 / 7 / 3 天）
        │
        ▼
风险预警 · 待审核（证照到期预警）
        │
        └── 人工确认 → 生成换证工单，下发商户
                │
                ▼
        商户小程序 · 工单（办理换证并上传新证照）
                │
                ▼
        审批记录 · 待审批（镇级审核）
                ├── 通过 → 归档（已通过）
                └── 驳回 → 商户补办换证 / 补材料后重新提交
```

**步骤说明：** 系统按「证照扫描规则」每日凌晨 02:00 扫描证照有效期，命中提醒节点（提前 90/60/30/7/3 天）生成到期预警 → 监管确认后生成换证工单 → 商户在线办理换证并上传新证照 → 镇级审核通过归档。证照类型包括健康证、食品经营许可证、营业执照、其他认证。

#### 分支流程

**分支一：报警不采纳（误报撤销）**

当报警属误报或证据不足时，监管人员在待审核详情中点击「不采纳」，报警状态变为「已撤销」，不生成工单。典型场景：置信度较低（如未戴帽子 0.55）、非供餐时段、设备检修期间的抓拍。

**分支二：工单驳回 → 重新整改（可多轮）**

镇级审核不通过时填写驳回原因退回商户；商户整改后重新提交，工单自动回到「待审批」可再次审核。支持多轮驳回，每轮驳回记录（时间、审核人、原因）均保留；同一工单累计驳回 3 次，系统自动关闭。

**分支三：商户申诉**

商户对报警或工单有异议时，可在小程序发起申诉（附证据材料，如完整监控录像）：

```text
商户提交申诉（附证据）
        │
        ▼
审批记录 · 待审批（镇级审核）
        ├── 审核通过 → 归档（已通过）· 撤销原报警 / 工单
        └── 驳回 → 需先整改，再重新提交申诉（可多轮）
```

申诉审核通过后撤销原报警；驳回则需商户先完成整改后再提交申诉。

**分支四：主体信息变更审批**

商户变更企业信息（名称、法人、经营项目、经营场所等）时，提交变更申请（系统自动生成变更前后对比表）：

```text
商户提交变更申请（变更前后对比）
        │
        ▼
审批记录 · 待审批（镇级审核）
        ├── 审核通过 → 归档 · 变更生效
        └── 驳回 → 商户修改后重新提交
```

变更审批期间企业信息只读，通过后自动生效。

#### 工单类型与状态对照

| 工单类型 | 触发来源 | 处理方式 |
|---|---|---|
| 整改 | AI 报警、证照到期 | 商户整改后提交材料 |
| 申诉 | 商户对报警/工单有异议 | 商户附证据申诉 |
| 变更 | 企业信息修改申请 | 商户提交变更前后对比 |

| 环节 | 状态值 | 说明 |
|---|---|---|
| 风险预警 | 待审核 → 待整改 → 已确认 | 人工复核 → 整改中 → 整改完成 |
| 风险预警 | 待审核 → 已撤销 | 人工不采纳（误报/证据不足） |
| 审批记录 | 待审批 → 已归档 | 审核通过 |
| 审批记录 | 待审批 ⇄ 已驳回 | 驳回后可多轮重提 |

#### 3.1.1 登录与角色权限

顶部栏提供「**演示切换**」按钮（区级 / 镇级），用于切换体验不同角色的界面与权限。右侧显示当前用户信息：

| 镇级 | 李所长 / 镇级管理员 · 城东镇 |

**角色权限**

| 角色 | 编号 | 权限说明 |
|---|---|---|
| 区级管理员 | R01 | 全量查看、统计分析、系统配置；**不能审批** |
| 镇级管理员 | R02 | 仅本镇数据、**唯一审批权**、一镇一账号 |

**区 / 镇关键差异：**

#### 3.1.3 主体管理

主体管理用于企业及从业人员的统一管理，支持树形结构浏览与分组圈选。

**企业台账**

1. 顶部按钮：**导出台账**、**分组管理**、**新增企业**。
2. 搜索框支持按企业名称 / 统一社会信用代码 / 许可证号检索。
3. 四个筛选下拉：所属镇、主体业态、所属科室、经营方式。

表格列：企业名称（含统一社会信用代码）、许可证号、所属镇、主体业态、所属科室、经营方式、营业状态、绑定关系、最近工单、操作（编辑 / 详情）。

绑定关系：展示 📱 绑定手机号、💬 绑定的微信（可多个）；点击「解绑」可解除绑定。当企业存在未处理整改工单或待审批变更时，解绑按钮禁用并提示处理完毕后方可解绑。

**分组管理（固定名单组）**

分组用于在站内信、公告中作为发送对象。点击「分组管理」打开分组弹窗。

- 分组类型：固定名单组（无动态/固定之分，统一为手动圈定名单）。
- 新增 / 编辑分组：填写分组名称 → 用「条件预筛 + 手动勾选」的方式圈选主体（条件筛选 + 搜索，左侧候选主体勾选、右侧已选主体汇总，支持一键全选当前结果与清空）。
- 查看：展示成员名单（名称、所属镇、业态、许可证号）。
- 删除：删除后站内信、公告中将无法再选择该分组（有二次确认）。

**新增企业**：点击「新增企业」填写企业信息并提交，用于补录新主体。

#### 3.1.4 视频监控

视频监控（明厨亮灶）用于远程非现场监管，实时查看辖区企业后厨画面。

1. **画面控制**：顶部可开启 / 关闭轮播（20 秒自动翻页，显示「轮播中第 X/N 组」）；画面布局支持 1 / 4 / 9 / 16 画面；支持全屏。
2. **筛选**：按镇 / 街道筛选，显示「X/Y 在线」。
3. **视频网格**：展示各摄像头卡片——在线显示 LIVE + 绿点 +「实时」，离线显示「⏻ 设备离线」；卡片下方标注企业名与安装位置（如「后厨-灶台」）。

#### 3.1.5 设备关联

设备关联用于「移动千里眼」设备与商户的关联管理，支持手动关联、自动匹配与批量导入。

1. **顶部按钮**：导入 CSV（批量更新关联）、导出 CSV、自动匹配。
2. **统计卡（4 张）**：设备总数、已关联、未关联、待确认。
3. **自动匹配**：展开面板，按 IP 地址段 / 安装位置 / 设备名称与商户信息计算匹配度；3 条规则各显示预估设备数；「开始自动匹配」后结果标记为「待确认」，需人工确认。
4. **筛选区**：状态（全部 / 已关联 / 未关联 / 待确认）、镇 / 街道（仅区级）、区域（后厨 / 前厅 / 仓库 / 出入口）、搜索框（UUID / SN / 商户 / 位置）。
5. **批量操作**：勾选设备后出现「已选 N 台」工具条，可「批量确认关联」（仅含待确认时）、「批量解绑」、「取消选择」。

表格列：复选框、千里眼 UUID、千里眼 SN、安装位置、所属镇、关联商户、匹配依据、关联状态、在线状态、操作。

关联状态：已关联（绿）/ 待确认（蓝）/ 未关联（黄）。行内操作：未关联→手动关联；待确认→确认 / 改关联；已关联→改关联 / 解绑。

手动关联：弹窗展示设备信息与最近关联记录快捷按钮，搜索并选择商户完成关联（同镇商户标「同镇」绿标）。

#### 3.1.6 风险预警

风险预警汇集 AI 报警记录与证照到期预警，按状态分类管理。

**列表与筛选**

- 顶部 Tab（带数量徽章）：**待审核 / 待整改 / 已确认 / 已撤销**。
- 主下拉「风险来源」：AI 报警记录 / 证照到期预警。
  - AI 报警筛选：紧急程度（高 / 中 / 低）、检测类型（鼠患 / 未戴口罩 / 未戴帽子 / 垃圾桶未加盖 / 陌生人闯入 / 明火离人 / 抽烟）、镇 / 街道（仅区级）。
  - 证照到期筛选：证照类型（健康证 / 许可证 / 营业执照 / 其他认证）。
- AI 报警表格列：编号、报警时间、企业名称、所属镇、检测类型、置信度(%)、紧急程度、状态、查看详情。
- 证照到期表格列：编号、企业名称、证照类型、证照编号、到期日期、剩余天数、预警级别、操作。

**AI 报警处置**

点击「查看详情」打开右侧抽屉：

1. 查看 AI 抓拍截图（含检测框与置信度）、报警基本信息。
2. 「待审核」状态下人工确认：**确认采纳**（绿）→ 状态变「待整改」；**不采纳**（白）→ 状态变「已撤销」。

**证照到期预警**

详情抽屉展示到期倒计时（大数字 + 进度条）、证照基本信息（含发证机关），并按证照类型给出「到期影响」法律后果提示。

#### 3.1.7 审批记录

审批记录用于整改 / 申诉 / 变更工单的审核流转。

**列表与筛选**

- 副标题按角色区分：区级「区级仅查看，审核权全归镇级」；镇级「您拥有审核权 · 驳回后等待商户重新提交」。
- Tab：**流转中**（待审批 + 已驳回）/ **已通过**（归档）。
- 筛选区：工单类型（整改 / 申诉 / 变更）、镇 / 街道（仅区级）、紧急程度、处理状态（仅流转中：待审批 / 已驳回）、搜索框（企业名 / 工单号 / 来源描述）。

表格列：工单编号、来源类型、企业名称、所属镇、工单类型（整改蓝 / 申诉橙 / 变更绿）、紧急程度、处理状态（已驳回标「第 N 次驳回」）或审批结果、发起时间、操作。

**审核操作（角色差异）**

| 角色 | 流转中工单操作 |
|---|---|
| 区级 R01 | 所有行仅「查看详情」（只读，无审核权） |
| 镇级 R02 | 待审批 →「进入审核」；已驳回 →「进入审核」（可再审核） |

已通过 Tab：所有角色均为「查看详情」。

**审核详情与流转**

详情抽屉包含：工单类型 / 紧急程度 / 状态；工单基本信息；驳回记录（每轮次时间、驳回人、原因）；来源描述与关联记录入口；类型专属区块（整改→整改说明 + 照片；申诉→申诉说明；变更→变更前后对比表）；处理进度（提交申请 → 审核中 → 审核完成）。

审核操作区：待审批状态可填写审核意见（**驳回必填**，限 500 字），点击「审核通过」（绿）或「驳回（需填写原因）」（红）。

#### 3.1.8 站内信

站内信用于与商户进行站内沟通，可主动发起或回复。

1. **发起站内信**：点击「+ 发起站内信」。
2. **选择发送对象**：支持「单个商户」或「自定义分组」（即主体管理中创建的固定名单组，显示各组成员数）。
3. 填写内容（可带附件），发送后该商户侧即生成一条待回复的站内信。
4. **列表**：按状态（待回复 / 已回复 / 已关闭）、镇 / 街道、关键词筛选；表格列含编号、企业名称、反馈内容、绑定手机号、提交时间、状态、操作。
5. **查看沟通**：进入对话详情，可回复商户。

#### 3.1.9 公告管理

公告管理用于向辖区商户下发监管公告，支持模板与重复时间。

**公告列表**

「已发布公告」表格列：标题、来源、公告范围、发布人、发布时间、状态、重复时间、操作。操作：**查看详情**、**编辑**（仅本人发布的公告）、**删除**（仅本人发布的公告）。

**新建 / 编辑公告**

点击「新建公告」或列表「编辑」打开公告抽屉，填写：

1. **来源**：根据账号自动带出（区市场监督管理局 / 镇市场监管所），不可修改。
2. **套用模板**（可选）：选中模板后自动填充标题与内容。
3. **公告范围**：全区下发（仅区级）/ 自定义镇（多选）/ 自定义分组（多选）；镇级仅可下发本镇。
4. **公告标题**（必填）、**详细内容**（必填）。
5. **重复时间**：不重复 / 每天 / 每周 / 每月 / 自定义（打开日历指定开始~结束日期范围）。
6. 点击「发布公告」（或编辑时「保存修改」）。

**模板管理**

点击「模板管理」打开模板抽屉：可「+ 新增模板」（填写模板名称、公告标题、公告内容），每个模板支持 **使用**（带入新建公告）、**编辑**、**删除**。

#### 3.1.10 知识库

知识库集成「腾讯 ima 知识库服务」，页面内嵌 iframe 展示食品安全法规、案例及操作指南，供监管人员查阅。本模块为外部服务集成，无本地自有内容。

#### 3.1.11 通知信息

通知信息为系统通知中心：

1. 右上「全部标为已读」。
2. Tab：**全部 / 未读（N）/ 已读**。
3. 每条通知含类型图标（严重 ⚠ / 普通 ●）、标题、正文、时间；未读左侧蓝边 + 加粗 + 蓝点。
4. 点击单条通知即标记为已读。

通知类型示例：工单超时、AI 报警、证照到期、工单审批完成、驳回次数超限（累计 3 次系统自动关闭）、摄像头断流、巡检报告生成完成。

#### 3.1.12 系统管理

系统管理**仅区级可见**，供授权人员进行系统配置与运维操作，共 6 个 Tab：

- **用户管理**：新增用户、编辑、禁用、重置密码；表格列含用户名、角色、所属组织、状态、最后登录、操作。
- **角色与权限**：3 张角色卡（R01 区级管理员 / R02 镇级管理员 / R03 商户负责人）。
- **组织架构**：区 → 镇二级树：区市监局 + 7 个镇所（城东 / 南桥 / 中心 / 北关 / 城南 / 西江 / 东湖），各显示企业数。
- **AI 报警规则**：7 条检测规则卡（鼠患、未戴口罩、未戴帽子、垃圾桶未加盖、陌生人闯入、明火离人、抽烟），各含灵敏度、去重时间窗、熔断阈值、启用状态。
- **证照扫描规则**：只读配置——扫描频率（每日凌晨 02:00）、提醒节点（90 / 60 / 30 / 7 / 3 天）、合并策略、去重规则、续提醒。
- **操作日志**：表格列含时间、操作人、角色、操作类型、详情、IP 地址。

### 3.2 商户端（小程序）使用指南

#### 3.2.1 登录与找回密码

**登录**

1. 打开小程序，进入登录页。
2. 输入**许可证号**（如 `JY111050XXXXXX`）。
3. 输入**密码**（首次登录使用监管下发的初始密码）。
4. 可选勾选「30 天内自动登录」，免去重复登录。
5. 点击**登录**，进入首页。

> 📌 **提示**：初始密码由监管人员通过短信发送至注册手机号，登录后建议立即修改密码（见 3.2.8 个人中心）。

**忘记密码**

1. 在登录页点击「忘记密码？」。
2. 输入**注册手机号**，点击「获取验证码」。
3. 输入收到的**短信验证码**，设置新密码。
4. 点击确认，完成密码重置后重新登录。

#### 3.2.2 首次建档（新增商户）

首次使用且平台尚未录入商户信息时，需先完成建档。分为两步：**身份验证 → 选择注册方式**。

**进入建档**

1. 在登录页点击「**新增商户**」按钮。
2. 进入首次验证页，填写：**主体名称、统一社会信用代码、法人姓名、联系电话**（均为必填）。
3. 可选点击「**微信一键授权**」，将账号与当前微信绑定。
4. 点击「**确认并进入**」。

**选择注册方式**（两种方式均需提交监管审核）

- **绑定已有商户**：平台已录入你的商户信息时选择。搜索并选择商户 → 输入监管线下提供的**验证码** → 提交绑定申请。
- **新增商户信息**：平台暂无你的商户信息时选择。填写企业信息创建新档案。

**填写新增企业信息**

1. **上传许可证文件**：上传食品经营许可证（支持 png / jpeg / pdf）。
2. **OCR 识别（推荐）**：点击「**OCR 识别许可证信息**」，系统自动识别并填入主体名称、统一社会信用代码、许可证号、主体业态、法人姓名。

   > 📌 **提示**：OCR 识别结果会自动填入并高亮显示。请务必核对识别结果是否与证件一致，如有误差请手动修正。

3. **填写主体信息**（带 `*` 为必填）：主体名称、统一社会信用代码（18 位）、许可证号、主体业态、法人姓名、联系电话、手机验证码。
4. **填写经营信息**：招牌名称、经营项目、经营面积、住所、所属镇、经营场所、所属市场所、连锁品牌、营业状态、扩展备注。
5. 点击底部「**提交**」，等待监管审核。

**审核状态说明**

| 状态 | 说明 | 操作 |
|---|---|---|
| 待审批 | 已提交，等待监管审核（1–3 个工作日） | 耐心等待 |
| 已驳回 | 审核未通过，附驳回原因 | 点击「重新填写」修改后再次提交 |
| 已通过 | 建档完成 | 使用初始密码登录（短信发送） |

#### 3.2.3 首页功能

- **公告滚动条**：滚动展示平台通知，点击查看详情。
- **风险预警概览**：展示报警记录与证照到期预警数量；可切换统计周期（日 / 周 / 月）；下方为预警时段分布折线图。
- **办事服务（快捷功能）**：预约指导、培训学习、检查记录（建设中）；进货查验、站内信、公告、更多。
- **最新工单动态**：展示最新工单列表，点击可跳转工单详情，点击「查看全部 →」进入工单页。

#### 3.2.4 工单管理

**列表与筛选**

1. 点击底部「**工单**」进入工单页。
2. 顶部按状态筛选：**待审核 / 已驳回 / 已通过**。
3. 支持按**关键词**搜索（工单标题、编号），以及**时间**筛选（全部 / 近一周 / 近一月 / 近三月）。

**工单类型**

| 类型 | 说明 | 示例 |
|---|---|---|
| 报警 | 设备/环境告警 | 后厨卫生整改、食材存储温度异常 |
| 换证 | 证照到期/年审提醒 | 食品经营许可证即将到期 |
| 申诉 | 商户发起的申诉 | 健康证过期申诉 |
| 信息变更 | 企业信息修改申请 | 变更经营地址 |

**详情与处理**

1. 点击任意工单进入详情页，查看工单内容。
2. 根据状态处理：**待审核**→按要求整改后反馈；**已驳回**→查看驳回原因，整改后重新提交；**已通过**→查看归档记录，有异议可发起申诉。

> 📌 **提示**：对待审核/已驳回的报警类工单，请及时整改并反馈，逾期可能影响后续监管评价。

#### 3.2.5 企业信息管理

点击底部「**企业**」进入企业页。

- **审批进度**：企业信息有修改审批时，顶部展示审批进度（提交审批 → 监管审核 → 已生效）。
- **基础信息**：查看企业完整档案；点击「编辑」可修改（提交后进入审批，审批期间只读，通过后自动生效）。
- **人员信息**：从业人员（含健康证有效期）、食品安全管理员（含培训证书编号）。
- **企业证照**：查看食品经营许可证、食品安全管理体系认证（ISO 22000）、从业人员健康证；点击「上传证照」可新增。
- **变更记录**：查看企业信息的最近更新时间与历史变更记录。

#### 3.2.6 通知接收（微信绑定）

在「我的 → 通知接收」中管理通知接收方式，支持**多成员绑定微信接收通知**。

**绑定我的微信**

1. 进入「我的 → 通知接收」。
2. 在「我的微信接收」区域点击「绑定微信」。
3. **强制录入名字（标识）**：填写真实姓名作为标识，便于管理端识别接收人。
4. 点击「确认绑定」，弹出微信**订阅消息授权**，点击「允许」完成绑定。

> 📌 **提示**：名字（标识）为必填项，不填写无法完成绑定。

**管理通知接收人**

- 查看清单（需**短信验证**）、编辑备注、移除成员；单个账号最多绑定 **10** 个成员。

#### 3.2.7 办事服务

**进货查验**

1. 首页 → 办事服务 → 点击「**进货查验**」。
2. 查看列表：默认展示已登记的货物（货物名、描述、附件、时间）。
3. 新增货物：点击右下角蓝色「＋」圆形按钮，填写货物名（必填）、货物描述（可上传附件），点击保存。

5. 删除货物：在详情表单中点击「删除货物」。

**站内信**

1. 首页 → 办事服务 → 点击「**站内信**」。
2. 查看列表；写站内信：点击右下角蓝色「＋」按钮，填写主题与内容（可上传附件、语音输入），点击发送。

**公告**：首页 → 办事服务 → 点击「**公告**」，查看平台发布的公告与提醒。

#### 3.2.8 个人中心

点击底部「**我的**」进入个人中心。

- **修改密码**：输入当前密码、新密码、确认新密码，点击确认修改。首次登录后请务必修改初始密码。
- **绑定 / 换绑手机**：换绑时先验证原手机号（短信验证码），再绑定新手机号；手机号用于找回登录密码。
- **其他**：帮助与反馈、关于（版本信息 / 隐私政策 / 用户协议）、退出登录。

### 3.3 常见问题（FAQ）

**管理端**

**Q1：为什么我（区级）看不到「进入审核」按钮？**
答：系统设定审核权全归镇级，区级只读；请由对应镇级账号完成审核。

**Q2：镇级为什么看不到「系统管理」菜单？**
答：系统管理仅区级可见，用于全局配置与运维。

**Q3：报警怎么从「待审核」变成「待整改」？**
答：在风险预警中打开报警详情，点击「确认采纳」即可转入待整改。

**Q4：工单驳回了还会回来吗？**
答：会。商户重新提交后，工单自动回到「待审批」状态；驳回记录会保留每一轮原因。

**Q5：分组是什么类型？**
答：固定名单组，通过「条件预筛 + 手动勾选」圈定主体，用于站内信、公告的发送对象。

**Q6：公告可以定时 / 重复发吗？**
答：可设置重复时间——每天 / 每周 / 每月，或「自定义」用日历指定日期范围。

**Q7：公告范围能同时选多个镇 / 多个分组吗？**
答：可以，自定义镇、自定义分组均支持多选。

**商户端**

**Q1：登录提示密码错误怎么办？**
答：检查许可证号是否正确；如忘记密码，点击「忘记密码」通过手机号重置。

**Q2：OCR 识别结果准确吗？**
答：OCR 为辅助录入功能，识别后请**务必人工核对**识别内容与证件一致，不一致请手动修改。

**Q3：建档提交后多久能通过审核？**
答：监管人员将在 **1–3 个工作日**内完成审核，请耐心等待；审核进度可在首页/企业页查看。

**Q4：绑定微信时为什么必须填写名字？**
答：名字作为接收人标识，便于管理端识别是哪个成员在接收通知，属于必填项。

**Q5：通知接收人最多能绑几个？**
答：单个账号最多绑定 **10** 个成员；查看清单、移除成员等管理操作需短信验证。

**Q6：工单被驳回了怎么办？**
答：查看驳回原因，整改后重新提交；如有异议可发起申诉。

**Q7：企业信息修改后为什么不能马上生效？**
答：信息修改需提交监管审批，审批期间信息只读，通过后自动生效。

### 3.4 注意事项

**管理端**

1. **角色边界**：区级不越权审批，镇级仅处理本镇数据。
2. **报警处置时效**：待审核报警请及时人工确认，避免处置滞后。
3. **驳回需填原因**：驳回工单必须填写原因，便于商户整改。
4. **分组维护**：删除分组后，站内信、公告将无法再选择该分组，删除前确认。
5. **公告范围与重复**：下发前核对范围（全区 / 自定义镇 / 自定义分组）与重复时间，避免误发或重复打扰。
6. **设备关联**：自动匹配结果需人工确认后方生效；CSV 导入按 UUID / SN 匹配，请核对格式。

**商户端**

1. **密码安全**：首次登录后立即修改初始密码，勿将密码告知他人。
2. **信息核对**：OCR 识别、表单填写均请核对无误后提交，避免因信息错误被驳回。
3. **及时处理工单**：对报警、换证类工单请及时整改反馈，避免逾期。
4. **证照有效期**：关注首页「证照到期预警」，提前办理延续，避免证照过期。
5. **通知接收**：绑定微信并授权订阅消息，确保能及时收到整改、告警通知；成员离职请及时移除。
6. **进货查验**：进货时及时登记，上传质检报告等附件，留存凭证备查。
