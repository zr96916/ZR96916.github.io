## 一、概述

### 1.1 产品简介

「食品安全智慧监管平台」（简称「智慧食安」）是一套面向食品安全监管的全流程数字化平台，分为**管理端（PC 端）**与**商户端（小程序）**两端：

- **管理端**：面向区局与各市场所监管人员，用于辖区食品经营主体统一监管、AI 报警处置、证照到期预警、工单审批、公告下发、站内沟通与系统运维。浏览器访问，无需安装。
- **商户端**：面向食品经营商户的移动端小程序，用于接收并处理整改工单、维护企业信息与证照人员档案、上报进货查验、与监管部门沟通。

两端通过「风险预警 → 整改工单 → 商户反馈 → 审批归档」形成闭环，数据实时同步。

**两端核心模块速览：**

| 端 | 核心模块 |
|---|---|
| 管理端（PC） | 数据中心、主体管理、视频监控、设备关联、风险预警、审批记录、站内信、公告管理、知识库、通知信息、系统管理 |
| 商户端（小程序） | 首页、工单、企业、我的（修改密码 / 绑定手机 / 通知接收 / 进货查验） |

| 镇级管理员（市场所） | 本所辖区 | 本所查看、预警人工确认、**工单审批（通过 / 驳回）**、公告与站内信下发 | 归属镇锁定；不能新增用户 |

**区 / 镇关键差异（培训重点）：**

1. 审批记录：区级页面提示「区级仅查看，审核权全归镇级」；只有镇级账号有「审批通过 / 驳回」按钮。
2. 主体管理：镇级新增企业时「所属市场所」已锁定为本所，无法跨镇。
3. 分组管理：分组按创建人隔离，只能看到并管理自己创建的分组；镇级只能圈选本镇主体。
4. 公告管理：区级可按全区或自选镇下发，镇级仅能向本镇下发；均只能删除本人创建的公告。
5. 系统管理：仅区级可见，「新增用户」仅超级管理员可操作。

### 2.2 业务总览：一张图看懂闭环

```text
【发现】                          【处置】                      【整改】                 【审核归档】
摄像头AI识别 / 证照扫描 ──► 风险预警（人工复核）──► 整改工单 ──► 商户端整改反馈 ──► 审批记录（镇级）──► 归档
                                    │                                                      │
                                    └── 不采纳 → 已撤销                                     └── 驳回 → 商户重提
商户提交变更 / 申诉 ──────────────────────────────────────────► 变更 / 申诉工单 ──► 审批记录（镇级）──► 生效
```

### 2.3 主流程一：AI 报警处置

```text
摄像头实时抓拍 → AI 识别违规（未戴帽子/头套、未戴口罩、未戴手套、抽烟、玩手机、明火、鼠患）
        │
        ▼
风险预警 · 待审核（监管查看抓拍截图与置信度，人工复核）
        │
        ├── 不采纳 ──────────────► 已撤销（误报，流程结束，不生成工单）
        │
        └── 确认采纳 ────────────► 待整改（生成整改工单，下发商户）
                                        │
                                        ▼
                          商户端 · 工单（整改并提交说明与照片）
                                        │
                                        ▼
                          审批记录 · 流转中（镇级管理员审核）
                                        │
                              ├── 审批通过 ──► 工单已通过（归档），预警 → 已确认
                              │
                              └── 驳回（审批意见）──► 已驳回 → 商户重提 → 回到待审核
```

**培训要点：**

1. 待审核报警的处置入口：风险预警 → 查看详情 → 人工确认 →「确认采纳 / 不采纳」。
2. 采纳后预警进入「待整改」，审批记录中出现对应整改工单。
3. 审核通过后预警转为「已确认」，整条链路闭环。
4. 已完成复核的预警不能修改确认结果（系统会提示）。

### 2.4 主流程二：证照到期预警

```text
证照扫描规则：每日 02:00 扫描 → 命中提醒节点（到期前 90 / 60 / 30 / 7 / 3 天）
        │
        ▼
风险预警 · 证照到期预警（同商户 + 同证件类型合并为一条）
        │
        ├── 人工确认通过 ──► 待整改（生成整改工单，下发换证）
        └── 人工确认不通过 ──► 已撤销（信息有误 / 已换证未更新）
        │
        ▼
证照过期当天 → 系统自动生成整改工单（无需另行确认）
        │
        ▼
商户上传新证照 → 镇级审批（通过归档 / 驳回补材料）
```

**培训要点：** 证照类型为营业执照、食品经营许可证、食品生产许可证、健康证 4 类；从业人员健康证在「主体管理 → 企业详情 → 从业人员」中维护，健康证状态分「有效 / 即将到期 / 已过期」。

### 2.5 主流程三：工单审批（镇级专属）

```text
商户端提交（整改反馈 / 申诉 / 主体变更）
        │
        ▼
审批记录 · 流转中（待审核）
        │
        ├── 审批通过 → 已通过（归档）：整改→预警已确认；申诉→撤销原预警；变更→即时生效
        │
        └── 驳回（审批意见必填，限 500 字）→ 已驳回 → 商户修改后重新提交 → 回到待审核
```

**培训要点：** 区级只读；镇级在详情页点击「审批通过」或「驳回」，驳回必须写明理由，商户端会展示该意见。

### 2.6 主流程四：公告与站内信触达

```text
管理端：公告管理 → 新建公告（全区 / 指定镇 + 全部主体 / 自定义分组）→ 发布
        │
        ▼
商户端：首页公告滚动条 → 查看详情

管理端：站内信 → 发起站内信（指定主体 / 自定义分组）→ 商户回复 → 管理员回复 → 关闭会话
        │
        ▼
商户端：首页 → 办事服务 → 站内信
```

### 2.7 分支流程

| 分支 | 触发场景 | 系统行为 |
|---|---|---|
| 误报撤销 | 抓拍误报、置信度低、非营业时段 | 待审核 → 不采纳 → 已撤销，不生成工单 |
| 驳回重提 | 整改不到位、材料缺失、变更信息有误 | 工单转「已驳回」，商户修改后重新提交回到待审核 |
| 商户申诉 | 商户对预警 / 工单有异议 | 生成申诉工单，审批通过后撤销原预警 |
| 主体信息变更 | 商户修改名称、法人、经营场所等 | 生成变更工单（带变更前后对比），审批期间信息只读，通过后生效 |
| 商户注册 / 绑定 | 新商户自助注册或绑定已有主体 | 生成变更工单（来源：商户注册），审批通过后开通商户账号 |
| 解绑手机 | 人员离职、手机号变更 | 管理端主体列表「解绑手机」，解除微信与手机号绑定 |
| 设备关联 | 新增摄像头、商户更换点位 | 手动关联 / 改关联 / 解绑；未关联设备不推送画面与告警 |

### 3.4 常见问题（FAQ）

**Q1：区级账号为什么没有「审批通过 / 驳回」按钮？**
答：审核权仅授予镇级管理员，区级在审批记录中为只读（页面提示「区级仅查看，审核权全归镇级」）。

**Q2：风险预警切到「AI 报警记录」是空的，但页签有数字？**
答：页签数量按当前来源统计。证照到期预警需把来源切到「证照到期预警」；若该状态确无记录会显示「该状态下暂无报警记录」。

**Q3：AI 报警如何从「待审核」转「待整改」？**
答：详情 → 人工确认 →「确认采纳」；点「不采纳」则转「已撤销」，不生成工单。

**Q4：证照预警什么时候产生？**
答：每日凌晨 02:00 扫描，到期前 90 / 60 / 30 / 7 / 3 天提醒；过期当天自动生成整改工单；同商户同类型合并为一条。

**Q5：设备显示「未关联」怎么办？**
答：「设备关联」→ 该行「手动关联」选择商户；或先「自动匹配」再逐条核对。

**Q6：视频显示「设备离线」怎么办？**
答：先核对设备在线状态与绑定关系，再联系设备维护方检查网络与供电，平台侧无法强制上线。

**Q7：为什么看不到同事建的分组？**
答：分组按创建人隔离，镇级只能圈选本镇主体。

**Q8：公告删不掉？**
答：只能删除本人创建的公告。

**Q9：商户端提交后多久生效？**
答：整改、申诉、变更工单均需所属市场所审核，一般 1–3 个工作日；变更审批期间企业信息只读。

**Q10：密码格式总提示不符？**
答：需 8–18 位，数字、字母、符号任意两种组合，不能纯数字 / 纯字母 / 含中文。

### 3.5 注意事项

1. **权限边界**：区级统筹配置不越权审批；镇级一镇一账号，勿共用账号。
2. **及时处置**：导航角标（风险预警、审批记录、站内信）提示待办，请按工作时限清理。
3. **驳回必留言**：驳回工单须写清整改要求（≤500 字），商户端可见。
4. **数据准确**：统一社会信用代码须 18 位；市场所、主体业态、经营方式影响统计与分派，谨慎选择。
5. **证照维护**：照片清晰（JPG/PNG ≤10MB），到期日与证件一致，否则预警节点失真。
6. **台账安全**：导出台账为原值未脱敏，按内部数据安全要求保管。
7. **触达前核对范围**：公告、站内信下发前确认全区 / 指定镇 / 分组，避免误发。
8. **演练用测试数据**：培训演练只用测试主体与分组。
9. **账号安全**：初始密码首次登录即改；人员变动及时在用户管理中禁用账号。
