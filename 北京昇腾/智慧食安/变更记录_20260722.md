## 1. 视频监控 — 轮播功能

**位置**：`VideoSurveillance` 组件

| 改动 | 说明 |
|------|------|
| 新增 `isCarouselOn` 状态 | 控制轮播开关 |
| 新增 `carouselIndex` 状态 | 当前显示的摄像头组索引 |
| 新增轮播按钮 | 位于画面布局按钮左侧，橙色闪烁表示轮播中 |
| 20 秒定时器 | `useEffect` + `setInterval`，按摄像头 ID 排序后每 20 秒切换一组 |
| 轮播提示 | 筛选栏显示"轮播中：第 X / Y 组" |
| 组大小 | 跟随画面布局设置（1/4/9/16 画面） |

**行为**：
- 开启轮播 → 按 ID 排序，每组显示 `layout` 个摄像头，每 20 秒自动切换
- 关闭轮播 → 恢复显示全部摄像头
- 切换布局/镇街筛选时自动重置到第 1 组
