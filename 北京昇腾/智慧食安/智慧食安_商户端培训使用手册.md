## 一、产品简介

「智慧食安」商户端是面向食品经营商户的移动端小程序，用于接收监管部门的整改通知、管理企业证照与人员信息、上报进货查验记录、绑定微信接收告警通知等。商户通过小程序即可完成信息建档、工单处理、证照管理等日常事务，实现食品安全管理的线上化。

**核心模块速览：**

| 模块 | 说明 |
|---|---|
| 首页 | 风险预警概览、办事服务快捷入口、最新工单动态 |
| 工单 | 查看/处理监管部门下发的报警、换证、申诉等工单 |
| 企业 | 查看与维护企业基础信息、人员信息、企业证照 |
| 我的 | 修改密码、绑定手机、通知接收、退出登录 |

底部导航栏共四个入口：**首页、工单、企业、我的**。

## 二、登录与找回密码

### 2.1 登录

1. 打开小程序，进入登录页。
2. 输入**许可证号**（如 `JY111050XXXXXX`）。
3. 输入**密码**（首次登录使用监管下发的初始密码）。
4. 可选勾选「30 天内自动登录」，免去重复登录。
5. 点击**登录**，进入首页。

> 📌 **提示**：初始密码由监管人员通过短信发送至注册手机号，登录后建议立即修改密码（见 [9.1 修改密码](#91-修改密码)）。

### 2.2 忘记密码

1. 在登录页点击「忘记密码？」。
2. 输入**注册手机号**，点击「获取验证码」。
3. 输入收到的**短信验证码**，设置新密码。
4. 点击确认，完成密码重置后重新登录。

## 三、首次建档（新增商户）

首次使用且平台尚未录入商户信息时，需先完成建档。分为两步：**身份验证 → 选择注册方式**。

### 3.1 进入建档

1. 在登录页点击「**新增商户**」按钮。
2. 进入首次验证页，填写以下信息（带 `*` 为必填）：
   - **主体名称**（必填）
   - **统一社会信用代码**（必填）
   - **法人姓名**（必填）
   - **联系电话**（必填）
3. 可选点击「**微信一键授权**」，将账号与当前微信绑定。
4. 点击「**确认并进入**」。

### 3.2 选择注册方式

系统提供两种方式，均需提交监管审核：

- **绑定已有商户**：平台已录入你的商户信息时选择。搜索并选择商户 → 输入监管线下提供的**验证码** → 提交绑定申请。
- **新增商户信息**：平台暂无你的商户信息时选择。填写企业信息创建新档案（见 3.3）。

### 3.3 填写新增企业信息

1. **上传许可证文件**：点击上传区域，上传食品经营许可证（支持 png / jpeg / pdf）。
2. **OCR 识别（推荐）**：上传许可证后，点击「**OCR 识别许可证信息**」，系统自动识别并填入以下字段：
   - 主体名称（/ 经营者名称）
   - 统一社会信用代码
   - 许可证号
   - 主体业态
   - 法人姓名

   > 📌 **提示**：OCR 识别结果会自动填入，并高亮显示已填入字段。请务必核对识别结果是否与证件一致，如有误差请手动修正。

3. **填写主体信息**（带 `*` 为必填）：主体名称、统一社会信用代码（18 位）、许可证号、主体业态（点击选择）、法人姓名、联系电话、手机验证码。
4. **填写经营信息**：招牌名称、经营项目、经营面积、住所、所属镇、经营场所、所属市场所、连锁品牌（无则不填）、营业状态、扩展备注。
5. 点击底部「**提交**」，等待监管审核。

### 3.4 审核状态说明

| 状态 | 说明 | 操作 |
|---|---|---|
| 待审批 | 已提交，等待监管审核（1–3 个工作日） | 耐心等待 |
| 已驳回 | 审核未通过，附驳回原因 | 点击「重新填写」修改后再次提交 |
| 已通过 | 建档完成 | 使用初始密码登录（短信发送） |

## 四、首页功能

### 4.1 公告滚动条

首页顶部为公告滚动条，滚动展示平台通知。点击可查看当前公告详情。

- 可切换统计周期：**日 / 周 / 月**。
- 下方为**预警时段分布**折线图，直观查看预警高发时段。

|---|---|

| 培训学习 | 在线培训（建设中） |

## 五、工单管理

### 5.1 工单列表与筛选

1. 点击底部「**工单**」进入工单页。
2. 顶部按状态筛选：**待审核 / 已驳回 / 已通过**。
3. 支持按**关键词**搜索（工单标题、编号），以及**时间**筛选（全部 / 近一周 / 近一月 / 近三月）。

### 5.2 工单类型

| 类型 | 说明 | 示例 |
|---|---|---|
| 报警 | 设备/环境告警 | 后厨卫生整改、食材存储温度异常 |
| 换证 | 证照到期/年审提醒 | 食品经营许可证即将到期 |
| 申诉 | 商户发起的申诉 | 健康证过期申诉 |
| 信息变更 | 企业信息修改申请 | 变更经营地址 |

### 5.3 工单详情与处理

1. 点击任意工单进入详情页。
2. 查看工单内容（报警来源、设备信息、时间等）。
3. 根据工单状态进行相应处理：
   - **待审核**：按要求整改后反馈/提交审核。
   - **已驳回**：查看驳回原因，整改后**重新提交**。
   - **已通过**：查看归档记录；如有异议可发起**申诉**。

> 📌 **提示**：对待审核/已驳回的报警类工单，请及时整改并反馈，逾期可能影响后续监管评价。

## 六、企业信息管理

点击底部「**企业**」进入企业页。

### 6.1 审批进度

当企业信息有修改审批时，页面顶部展示审批进度（提交审批 → 监管审核 → 已生效）。

### 6.2 基础信息

- 展示企业完整档案：主体名称、统一社会信用代码、许可证号、主体业态、法人姓名、联系电话、招牌名称、经营项目、经营面积、住所、经营场所、所属镇、所属市场所、连锁品牌、营业状态、扩展备注。
- 点击「编辑」可修改，提交后进入审批流程。
- **审批期间信息只读**，通过后自动生效。

### 6.3 人员信息

- **从业人员**：查看/添加从业人员及其健康证有效期。
- **食品安全管理员**：查看/添加食品安全管理员及其培训证书编号。

### 6.4 企业证照

- 查看已上传的证照：**食品经营许可证、食品安全管理体系认证（ISO 22000）、从业人员健康证**。
- 点击「上传证照」可新增证照。

### 6.5 变更记录

查看企业信息的最近更新时间与历史变更记录。

## 七、通知接收（微信绑定）

在「我的 → 通知接收」中管理通知接收方式，支持**多成员绑定微信接收通知**。

### 7.1 绑定我的微信

1. 进入「我的 → 通知接收」。
2. 在「我的微信接收」区域点击「绑定微信」。
3. **强制录入名字（标识）**：填写真实姓名作为标识，便于管理端识别接收人。
4. 点击「确认绑定」，弹出微信**订阅消息授权**，点击「允许」完成绑定。

> 📌 **提示**：名字（标识）为必填项，不填写无法完成绑定。

### 7.2 管理通知接收人

- **查看清单**：查看已绑定的接收人列表（需**短信验证**，验证码发送至管理手机号）。
- **编辑备注**：为接收人添加备注（如「店长老王」），便于识别。
- **移除成员**：移除后该成员立即停止接收通知。
- **数量上限**：单个账号最多绑定 **10** 个成员。

## 八、办事服务

### 8.1 进货查验

记录并管理进货货物信息，默认显示货物列表。

1. 首页 → 办事服务 → 点击「**进货查验**」。
2. **查看列表**：默认展示已登记的货物（货物名、描述、附件、时间）。
3. **新增货物**：点击右下角**蓝色「＋」圆形按钮**，进入表单：
   - **货物名**（必填）
   - **货物描述**（可**上传附件**，如质检报告、供应商资质）
   - 点击「保存」完成新增。
4. **编辑/查看详情**：点击列表中的货物可查看或修改。
5. **删除货物**：在详情表单中点击「删除货物」即可删除。

### 8.2 站内信

与监管人员进行在线沟通。

1. 首页 → 办事服务 → 点击「**站内信**」。
2. **查看列表**：展示往来站内信。
3. **写站内信**：点击右下角**蓝色「＋」圆形按钮**，填写主题与内容（可上传附件、语音输入），点击发送。
4. **回复**：打开某条站内信，可回复对方。

### 8.3 公告

首页 → 办事服务 → 点击「**公告**」，查看平台发布的公告与提醒。

1. 「我的 → 修改密码」。
2. 输入**当前密码**、**新密码**、**确认新密码**。

2. 换绑时先验证原手机号（短信验证码），再绑定新手机号。
3. 手机号用于找回登录密码，请绑定常用号码。

### 9.3 其他

- **帮助与反馈**：常见问题、站内信入口。
- **关于**：版本信息、隐私政策、用户协议。
- **退出登录**：点击底部红色「退出登录」按钮。

## 十、常见问题（FAQ）

**Q1：登录提示密码错误怎么办？**
答：检查许可证号是否正确；如忘记密码，点击「忘记密码」通过手机号重置。

**Q2：OCR 识别结果准确吗？**
答：OCR 为辅助录入功能，识别后请**务必人工核对**识别内容与证件一致，不一致请手动修改。

**Q3：建档提交后多久能通过审核？**
答：监管人员将在 **1–3 个工作日**内完成审核，请耐心等待；审核进度可在首页/企业页查看。

**Q4：绑定微信时为什么必须填写名字？**
答：名字作为接收人标识，便于管理端识别是哪个成员在接收通知，属于必填项。

**Q5：通知接收人最多能绑几个？**
答：单个账号最多绑定 **10** 个成员；查看清单、移除成员等管理操作需短信验证。

**Q6：工单被驳回了怎么办？**
答：查看驳回原因，整改后重新提交；如有异议可发起申诉。

**Q7：企业信息修改后为什么不能马上生效？**
答：信息修改需提交监管审批，审批期间信息只读，通过后自动生效。

## 十一、注意事项

1. **密码安全**：首次登录后立即修改初始密码，勿将密码告知他人。
2. **信息核对**：OCR 识别、表单填写均请核对无误后提交，避免因信息错误被驳回。
3. **及时处理工单**：对报警、换证类工单请及时整改反馈，避免逾期。
4. **证照有效期**：关注首页「证照到期预警」，提前办理延续，避免证照过期。
5. **通知接收**：绑定微信并授权订阅消息，确保能及时收到整改、告警通知；成员离职请及时移除。
6. **进货查验**：进货时及时登记，上传质检报告等附件，留存凭证备查。
